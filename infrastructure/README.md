# Infrastructure

This directory contains deployment and infrastructure configuration for Boost Market.

## Components
- **Continuous Integration (CI):** Automated quality verification workflow via GitHub Actions (`.github/workflows/ci.yml`). See [ci/README.md](ci/README.md).
- **Docker Compose (Planned):** Local multi-container development environment (PostgreSQL, Redis).
- **Production Deployment (Planned):** Cloud Run manifests and Terraform definitions.
